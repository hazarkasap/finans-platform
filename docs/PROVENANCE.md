# Provenance

The application code, project concepts, tests, and documentation are maintained by the repository owner. Synthetic users and finance records were written specifically for this educational showcase and do not represent a real person, account, debt, bill, measurement, or transaction. No third-party media or financial dataset is bundled.

The interface uses open-source dependencies, including Next.js, React, Auth.js, Prisma, Recharts, Radix-derived components, Tailwind CSS, Zod, and Vitest. Dependencies retain their own licenses. The repository currently has no project license.
